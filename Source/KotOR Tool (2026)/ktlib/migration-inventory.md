# Transposition inventory

Source scan: 2026-11-16, `treya/v1.0.3.5`. This covers the production and developer-tool VB, C# and Python sources under this solution, excluding generated output and the new isolated test harness (documented in README.md); binary-only dependencies are catalogued in dependencies.md and are not translatable source.

This is a static triage inventory, not a semantic audit of every method. Types, callable names and coupling flags are extracted from source text; commented code is excluded where possible. Flags can miss indirect dependencies. Before each port, read the complete implementation and callers and apply the stage gates in [transposition instruction.md](../transposition%20instruction.md). Uncompiled source must not silently become active.
