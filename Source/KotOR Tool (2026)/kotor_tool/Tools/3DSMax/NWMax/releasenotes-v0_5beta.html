NWmax v0.5beta

  1. Activate/Deactivate all animations buttons added to the model base properties.
  2. Moved the export directory edit box and buttons to the top of the MDL Base Parameters rollout to make them more visable for the majority of people
  3. Up/Down sequencing buttons for animation list
  4. Correction for alphakey importing on emitters and trimesh modifier
  5. Better identification of problem WOK faces using a precalc feature on the Walkmesh modifier
  6. Support for lens flares in AuroraLight helper
  7. Changed way AuroraLight stores the light colour details to better support animation
  8. Import routine updated to correctly support:
    • Lens flares
    • transparencyhint
    • tilefade
  9. Added further dummy node creation support in model base wizard for Creatures and Placeables (Other type)
  10. Added some help text on what effect "transparency hint" has in the Trimesh Modifier
  11. Continued refinements to the WOK aabb code
  12. Monster Node creation tool (A HotU specific feature)
  13. Look for model textures in gmax/maps if not in directory with model during import
  14. Auroralights supports animated negative light values correctly
  15. Corrected export of "use" nodes on placeables to the pwk and dwk file
  16. Corrected a number of minor import and export bugs (that covers a multitude of sins doesn't it)
  17. Scale Wizard now correctly supports Skins and calcs the new animscale value based on the original animscale value not 1.0. Note: issues can arise on scaled skins which are due to the way vertexes are linked to bones, not to do with the way the scale util works
  18. New compact export format allowing MASSIVE export speed improvements on large models. Speed tests on large tile groups indicate improvements with a magnitude of 6x faster
  19. Support for script plugins to NWmax. The flame emiiter prefab has been converted to a NWmax plugin as an example
  20. Armour & Robe Maker - a system that allows the scaling of base models (armour pieces or HotU robes) to new race variations. The armour side of this utility is a "simpler" gmax native version of the NWNArmoury.  NB: loading of model pieces based on a file pattern into Nwmax (gmax) on to an armour "manakin" will be added shortly post v0.5 as a patch
  21. Added a sanity check to prevent use of "Export-All" on scenes which contain Skins.  This prevent a NWmax script crash
