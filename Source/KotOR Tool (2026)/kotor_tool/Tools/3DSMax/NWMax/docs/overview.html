 NWmax Overview

NWmax is designed along the same lines as the Aura scripts from Bioware and the MDL Suite. In fact those original works provided some of the original code that started NWmax off many months ago.  Anyway, the point is NWmax uses Helper Objects and Modifiers to hold all the Aurora Game Engine data the NWN needs for a model.

It is worth while reading about the concepts of modifiers in the gmax user guide and the gmax tutorial files. The key concept is that each modifier performs something on the meshes data and passes the resulting mesh up to the next modifier in the stack.  Some modifiers actually do nothing to the mesh other than provide a means of holding extra data against that mesh. This is what the Aurora modifiers do. The do not change the mesh in any way. All they do is hold Aurora Engine specific data against the mesh for use by the NWmax export functions.

The Model Base

The UI for the model base is very similar to that used in Waylands scripts.  The key difference is that data held on the model base will determine WHERE the model will be exported to. The key to this is the edit box just above the Export buttons.  This edit is used to hold the directory path to where you want to export your model. It can be to a specific export directory like that listed in the example or it could be to the NWN override directory.  Now that a user can export models from NWmax quickly (thanks to gmax Snoop) you can save variations of you work as gmax native files and export out to your test areas quickly. So long as you have saved "safe" gmax versions of your work you can always roll-back if you do something you don't like.
