# VB Project Metadata

This directory contains VB/Visual Studio generated metadata:

- `AssemblyInfo.vb` defines application identity, attribution, COM GUID and assembly version `1.0.3.04`.
- `Resources.resx` and `Resources.Designer.vb` define strongly typed embedded resources.
- `app.manifest` controls Windows application manifest behavior.

Use Visual Studio/resource tooling for resource changes and regenerate `Resources.Designer.vb`; do not hand-edit generated code. Coordinate version changes with the root [versioning guide](../../versioning.md). Preserve attribution and verify the manifest/resource outputs in both Debug and Release x86 builds.
