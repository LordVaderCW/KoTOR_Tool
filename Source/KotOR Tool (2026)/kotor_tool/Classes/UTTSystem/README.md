# UTT Trigger System

`clsUTT` is the GFF specialization for trigger templates. `frmUTT_Editor` exposes geometry-related trigger data, trap/transition behavior, faction and scripts.

Geometry lists and point order are structural data; do not normalize or reorder them without visual/module tests. Test transition versus generic/trap triggers, empty/complex geometry, localized names, key/tag/link fields and all script hooks in both games.
