# UTP Placeable System

`clsUTP` is the GFF specialization for placeable templates. `frmUTP_Editor` owns the exposed schema and shared inventory/script controls.

Test appearance, animation/state, use/lock/trap flags, hardness/hit points, faction, conversations, scripts, key/tag fields, inventory and localized text across both games. Preserve unknown fields and numeric 2DA IDs even if the UI cannot resolve a label.
