# UTW Waypoint System

`clsUTW` is the GFF specialization for waypoint templates. `frmUTW_Editor` edits map-note, localized label, tag/ResRef and waypoint flags.

Preserve map-note enabled state separately from empty text and retain language/StrRef representation. Test ordinary waypoints, map notes, transition/destination metadata, embedded/TLK strings and KoTOR I/II variants.
