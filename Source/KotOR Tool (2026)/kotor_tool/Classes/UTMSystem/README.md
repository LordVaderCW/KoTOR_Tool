# UTM Merchant System

`clsUTM` is the GFF specialization for merchant/store templates. `frmUTM_Editor` manages store metadata and inventory lists.

Inventory entries combine ResRefs with quantities/pricing/availability fields and may be shared with the inventory editor. Keep ordering and duplicate entries when they are meaningful. Test empty and large inventories, markup/markdown values, infinite stock, localized names, conversations/scripts and missing referenced item templates.
