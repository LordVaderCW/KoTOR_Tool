# 7-Zip 26.01

`7z.exe`, `7z.dll` and `7-zip.dll` are copied to output for generic `.7z` and RAR plugin package extraction. Managed ZIP extraction runs first for ZIP packages. When 7-Zip is used, quote paths, enforce timeout/exit code, validate the extracted tree afterward and retain licensing/provenance. Do not use it to bypass traversal checks.
